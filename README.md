## CN2 GIA 是条什么线路，为什么比普通 VPS 贵

搬瓦工官网对这条线路有一段很直白的解释，值得先看懂再掏钱。

国内访客到海外服务器的路径，取决于电信、联通、移动三家运营商给的“通道”。常见的有几档：

| 线路类型 | 特点 | 实际体验 |
| --- | --- | --- |
| 163 骨干网（AS4134） | 最便宜、容量大 | 晚高峰拥塞，丢包率可能高达 30% 以上 |
| CN2 GT（AS4809 GT） | 电信优化，但 2019 年后同样拥塞 | 比普通线路贵，晚高峰改善有限 |
| CN2 GIA（AS4809 GIA） | 电信最高等级，独立低负载通道 | 全程稳定、低丢包，建站/视频会议/游戏都合适 |
| CTGNet（AS23764） | 电信新网络，实际表现与 GIA 基本相当 | 可视作 GIA 的替代 |

一句话概括：**GIA 是三家运营商里最贵、也最稳的通道，带宽成本极高**，官方提到部分市场 1Gbps 的 GIA 转接月成本可达约 10 万美元量级。这也解释了为什么 CN2 GIA 套餐比同配置普通 VPS 贵一大截——钱主要花在线路上，不是硬件上。

另外有个官方明说的缺点要知道：GIA 通道容量有限，**不抗 DDoS**，一旦被攻击 IP 可能被临时屏蔽。做容易挨打业务的话，这条线路不是正确选择。
